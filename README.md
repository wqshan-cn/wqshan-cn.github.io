# 小单 · At the intersection
科研交流、开源分享与个人记录的静态主页。

## 当前版本

本轮新增 Reasonix 项目简介、PR 的实际作用说明，以及「未来规划」三个方向：继续生信分析、参与开源贡献、学习 vibecoding。项目介绍依据官方 README：https://github.com/esengine/DeepSeek-Reasonix ，概念工作流明确标为示意，不冒充产品截图。

配色已按最新审核意见统一为曜石黑、银白高光和少量暖金，集中在 theme-editorial.css。通过静态反射、边缘高光和局部光照增强玻璃质感，保留此前性能优化，不增加实时大面积模糊。论文图保留原始白底与科学配色。未来规划使用原创 SVG 示意与有限时长动画，可手动重播，遵循减少动效设置。Moonshot 仅作为视觉节奏参考，未复用其图片或视频。

手机布局将玻璃环移到视线边缘，让标题和按钮保持清楚；窄屏导航保留完整章节入口。贡献数字分开呈现已合并 PR 和维护者署名，避免混淆。

本地动效增强：首屏与成果数字错峰入场、开源流程逐项出现、未来规划卡片轻移入场、近况段落展开过渡。新增动画仅改变透明度和位置，不循环、不增加大面积模糊；关闭动效或进入后台时取消动画。

### 字体系统

typography.css 统一管理标题、正文、英文与数字的层级。中文正文采用 Noto Sans SC，衬线标题采用 Noto Serif SC，英文与数字采用 Manrope。字体来源为 Google Fonts，SIL Open Font License 随字体保存在 assets/fonts/。

三个 WOFF2 均为本地文件，合计 342,912 字节；中文可变字重范围 400–600，Manrope 为 300–600。使用 font-display: swap 和首屏中文字体预加载，不依赖访客访问远程字体服务器。

中文字体按当前 HTML、脚本中的字符生成子集；增加文案时如引入新字符，应更新子集，未覆盖字符会自动回退到系统字体。科学图片中的文字未修改。

## 设计
Liquid Glass × Scientific Editorial：曜石黑底色、银白高光与少量暖金，半透明表面、边缘反射与克制阴影。玻璃用于导航和交互容器，正文保持清晰对比。

- 首屏：居中大标题、玻璃环形构图与浮动身份标签。
- 关于：错位杂志排版、学科大字、三个非卡片式成果数字。
- 科研：独立展览画布和悬浮说明；桌面随滚动切换，手机点击或滑动切换。
- 开源：侧栏索引与案例详情，手机改为横向标签。
- 近况：原生可展开条目；经历：大年份与章节叙事。
- 联系：大幅玻璃面板，显眼邮箱和复制反馈。

## 运行
无需构建或在线字体。可以直接打开 index.html，或使用 Python 3：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765/ 。GitHub Pages 从 main 分支发布。

## 文件
- index.html：语义化页面、内容与无脚本回退。
- styles.css：玻璃材质变量、章节布局与响应式规则。
- script.js：图册、案例标签、滚动展览、渐入、邮箱复制与动效偏好。
- assets/research-figures/：三张真实论文主图的 WebP 预览，保留完整原图供弹窗查看；不提交 TIFF。
- assets/favicon.svg：网站图标。历史插画保留但新版不加载。

## 交互与无障碍
- 图片支持点击、左右键、首页/末页键、触控滑动与完整图弹窗；弹窗支持 Escape 和焦点返回。
- PR 标签支持点击和方向键；Now 条目使用原生 details。
- 系统减少动效优先；页脚开关保存在本地。关闭动效时取消桌面长滚动展览、渐入和持续动画。
- 渐入默认不隐藏正文；滚动和指针反馈按需使用 requestAnimationFrame。
- 玻璃环离开视口或页面进入后台后停止持续动画。
- 大面积玻璃面板以透明渐变、高光和阴影表现材质，不实时模糊背后内容；顶部小尺寸导航在桌面和手机端使用局部背景模糊。
- 滚动处理先读取位置，再在章节或导航状态发生变化时更新，避免每帧重复写入导航属性。
- 无 JavaScript 时所有贡献内容和联系信息可读，并提供三张完整论文图链接。
- 邮箱复制不可用时提示手动复制，mailto 始终保留。
