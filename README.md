# 小单 · Personal field notes

一个用于科研交流、开源分享和个人记录的静态主页。

## 查看网页

直接打开 `index.html` 即可。全部图片、样式和脚本都在本仓库中，不依赖在线字体或构建工具。

如已安装 Python 3，也可以在仓库目录启动本地预览：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8765 。邮箱复制功能需要浏览器允许剪贴板访问；不支持时页面会提示手动复制，邮箱链接始终可用。

## 文件

- `index.html`：个人介绍、经历、作品及联系信息。
- `styles.css`：配色、字体、响应式布局和轻量动效。
- `script.js`：概念散点图、导航当前位置和邮箱复制反馈。
- `assets/curiosity.svg`：原创细胞与代码概念插画。
- `assets/favicon.svg`：网站图标。

## 设计说明

原版有温暖的人文基调，但内容层级被连续的大段文字、标签和重复卡片削弱；首屏强制加载动画延迟阅读，移动端隐藏导航，联系邮箱还是示例地址。原版还存在两个 main 元素，以及在减少动效设置下仍持续运行的视差与打字循环。

新版采用“科研手记 × 个人杂志”的方向：

- 米白纸感、墨绿色文字和朱红色批注，搭配中文衬线标题与易读的正文。
- 首屏直接说明个人身份；原创概念插画呼应医学、生物信息与 AI。
- 按“认识我 → 探索与实践 → 近期兴趣 → 成长经历 → 联系”组织阅读。
- 科研、开源与个人主页提供不同展示方式；已知仓库链接可直接访问。
- 页面即时呈现，保留系统滚动和轻量交互；适配手机、键盘操作、减少动效及无脚本阅读。

## 动效

- 首屏标题分三行错峰入场，朱红下划线模拟笔迹绘制。
- 细胞插画以 12 秒周期缓慢浮动，桌面鼠标移动可产生轻微景深反馈。
- 正文、成果、经历与联系区在进入视口时渐入；研究散点分四簇展开。
- 代码卡片悬停舒展，合并勾号渐入；按钮具有扫光与箭头反馈。
- 顶部显示阅读进度，时间线随滚动逐步描绘；Now 星号缓慢旋转。
- 页脚提供动效开关，并在本地记住选择。系统“减少动态效果”优先，切换后即时生效。
- 持续动画在离开视口或标签页进入后台时暂停；滚动处理使用按需帧更新。
- 关闭 JavaScript 时正文仍直接可读。
